# DrinkMenu
I created this project in order to learn, how data is grabbed from API's and how it is done in code, additionally, I wanted to learn Razor pages and their syntax. For a more interesting terminal I used [Spectre Console](https://spectreconsole.net/) to add color and tables.

### How the project functions for now:
1. Run without debugging in Visual Studio or your IDE of your choice
2. The user is prompted with a welcome message
   
<img width="839" height="48" alt="image" src="https://github.com/user-attachments/assets/4beda330-4719-43fb-9433-5685b748d79e" />

4. The user has to choose to either search the drink by category or drink name
5. After the making the choice the user will either be prompted with a category list or be asked to enter a name
